# Mi Vida

App personal instalable (PWA) para iPhone: rutina, finanzas, plan de deudas, hábitos, tareas y metas, proyectos, ejercicio, check-in diario, logros y más.

- Abre https://arizpesalvador56-dev.github.io/Mi-Vida/ en Safari → Compartir → Agregar a pantalla de inicio.
- Los datos se guardan solo en el teléfono (localStorage). Usa Ajustes → Respaldo para descargarlos.
- Sin dependencias ni build: HTML, CSS y JavaScript.
